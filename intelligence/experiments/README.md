# Deneyler

Her deney bir dosyadır. **Başarısız deneyler silinmez.**

- Dosya adı: `EXP-XXX-kisa-ad.md`
- Asgari içerik:
  - Hipotez (tek cümle, ölçülebilir)
  - Ölçüt ve başarı eşiği (deneyden önce yazılır)
  - Süre / örneklem
  - Maliyet (para + zaman)
  - Sonuç: Başarılı / Başarısız / Belirsiz
  - Neden bu sonuç çıktı
  - Öğrenim → `company/lessons.md` kaydı
